# ScoutXI 足球球探程序（基础版）

一个可直接在 PyCharm 中运行的本地 Web 应用，让足球球迷查询球员与俱乐部资料，并按位置约束规划、保存自己的阵容。

## 范围

已实现：搜索与筛选、球员详情、俱乐部赛季阵容、4-3-3 / 4-2-3-1 阵容画布、首发/替补/队长、保存、收藏、个人球探报告、同步状态。

明确未实现：高级数据分析、雷达图、视频识别、AI 推荐。

## 启动

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

在浏览器打开 http://127.0.0.1:8000 。首次启动会自动创建 `data/scoutxi.db` 并写入本地演示数据。

在 PyCharm 中，将解释器设为项目的 `.venv` 后，直接运行 `run.py` 即可。

## 数据说明

程序初次使用离线种子数据演示完整流程。配置具有当前赛季权限的 API-Football 套餐后，服务端会读取其当前阵容与头像链接；头像始终从远程加载，不会把图片下载或保存到本地。免费套餐目前只开放至 2024 赛季，程序会拒绝把旧名单写成最新名单。

## 保持当前名单

优先设置具有当前赛季权限的 `API_FOOTBALL_KEY`（示例见 `.env.example`）后，使用“数据状态”中的刷新操作，或请求 `POST /api/admin/sync`。同步器先发现英超、西甲、意甲、德甲、法甲全部球队，再请求每队当前球员名单和远程头像 URL。若套餐允许并仍有每天 100 次免费额度，首次同步会安全处理最多 90 支球队，剩余球队在额度重置后再次点击刷新即可完成。免费密钥不开放当前赛季时会明确停止，不会回退写入 2024 的历史名单。旧名单会标记为历史记录，保留既有阵容和球探报告引用。密钥只在服务端读取，绝不会发送给浏览器。`FOOTBALL_DATA_API_TOKEN` 保留为独立的 8 支球队备用同步来源。

阵容编辑器按位置区域约束首发球员：球场由下向上进攻，GK 固定在底部、后卫在后场、中场在中场、ST 在最前端；不兼容的位置无法进入该区域。

## 安全与隐私

API 密钥只能写在本机 `.env` 中，不能提交到 GitHub；该文件、SQLite 数据库、日志、虚拟环境和 IDE 配置均已被 Git 忽略。程序默认仅监听 `127.0.0.1`。如果改为局域网或公网监听，应先为管理同步接口增加认证。
