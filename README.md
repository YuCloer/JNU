## About

I design and build practical software around real workflows: AI-assisted products, local automation, and tools that turn structured data into useful decisions.

My engineering priorities are clear interfaces, reproducible local development, privacy-aware data boundaries, and documentation that makes a project easy to evaluate and extend.

## Engineering focus

- **AI products** — combine LLMs, structured data, and explicit workflows into usable applications rather than isolated demos.
- **Reliable automation** — design for authentication expiry, retries, duplicate events, and recoverable failure.
- **Privacy-aware delivery** — keep sensitive inputs local by default and make external observability opt-in.
- **Product-minded implementation** — document scope, constraints, setup, and known limitations so the work can be reviewed honestly.
