# Bellman 最优性更新 vs 优势学习 (Advantage Learning)

## 作业说明
这是强化学习课程的第一次作业，主要任务是实现并对比 **Bellman 最优性更新** 和 **优势学习 (Advantage Learning)** 两种动态规划算法在 ChainWalk 环境下的表现。

## 我是怎么做的

### 1. 环境搭建
首先按照题目要求构建了 ChainWalk 环境：
- **状态空间**：11个状态 (s0-s10)
- **动作空间**：2个动作 (向左/向右)
- **转移概率**：按指令方向转移概率 0.7，反向 0.3
- **边界处理**：在端点执行越界动作时保持原地不动
- **奖励函数**：
  - s0: +3 (左端点高奖励)
  - s1-s4: -1 (左侧惩罚区)
  - s5: 0 (中间中性)
  - s6-s10: +1 (右侧奖励区)

### 2. 算法实现
#### Bellman 最优性更新
标准的 Q-learning 更新公式：
```
Q(s,a) = R(s) + γ * Σ P(s'|s,a) * max_a' Q(s',a')
```
每次迭代都用下一状态的最大 Q 值来更新当前 Q 值。

#### 优势学习 (Advantage Learning)
在 Bellman 更新基础上增加了一个优势项：
```
Q(s,a) = R(s) + α * [Q(s,a) - max_a' Q(s,a')] + γ * Σ P(s'|s,a) * max_a' Q(s',a')
```
这里的 `α` 是优势系数，作用是放大不同动作之间的 Q 值差异，让策略更明确。

### 3. 评估指标
按照题目要求计算了两个关键指标：

**性能界 (Performance Bound)**
- 计算当前策略的值函数 V^π 与理论最优值函数 V* 的无穷范数差距
- `||V* - V^π||_∞`
- 这个值越小，说明策略越接近最优

**动作间隔 (Action Gap)**
- 计算每个状态下两个动作 Q 值的平均差异
- `mean(|Q(s,左) - Q(s,右)|)`
- Action Gap 越大，策略越确定；太小会导致策略模糊

### 4. 理论最优解推导
为了验证算法正确性，我手动推导了理论最优值函数：
- 最优策略显然是"始终向左"(因为 s0 奖励最高为+3)
- 通过解线性方程组得到每个状态在"始终向左"策略下的真实值
- 用这个作为基准来评估迭代算法的收敛情况

### 5. 可视化
用 matplotlib 画了两张图：
1. **性能界对比图**：展示两种算法随迭代次数增加，策略如何逼近最优
2. **Action Gap 演化图**：展示优势学习如何放大动作差异

## 运行代码
```bash
python chainwalk_dp.py
```

## 主要发现
1. 两种算法最终都收敛到了最优策略(始终向左)
2. Advantage Learning 的 Action Gap 明显更大，策略更明确
3. 在深度强化学习中，更大的 Action Gap 有助于提高训练稳定性
